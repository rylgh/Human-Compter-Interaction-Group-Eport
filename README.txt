MULTI-PAGE GROUP EPORTFOLIO

HOW TO PREVIEW
1. Extract this ZIP file.
2. Open the group_eportfolio_multipage folder.
3. Double-click index.html.
4. Use the top navigation to move between separate pages.

PAGES INCLUDED
- index.html: Home / briefing page
- group.html: Group introduction and four member profiles
- activities.html: Learning activities
- takeaways.html: Individual reflections
- performance.html: Performance tasks by term
- assignments.html: Assignments by term
